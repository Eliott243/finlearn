Politique de confidentialité

Dernière mise à jour : 18 septembre 2026

FinLearn est une application d’éducation financière. Elle ne crée pas de compte en ligne et ne vend pas de données.

Données stockées sur l’appareil

  • Progression (leçons, quiz, badges, streak)
  • Préférences (pays, devise, notifications)
  • Avatars, certificats, objectif d’épargne, code de parrainage local
  • Caches optionnels (actualités, taux de change) pour le mode hors ligne

Réseau

Si vous utilisez les actualités ou le comparateur de devises, l’app interroge des flux publics (RSS / API de change). Aucun identifiant de compte n’est envoyé.

Notifications

L’astuce du jour n’est envoyée que si vous l’activez. Vous pouvez la couper dans Paramètres.

Vos droits

Dans Paramètres, « Supprimer mes données » efface tout le contenu local de FinLearn sur cet appareil.
